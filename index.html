Metronome

Pressing play tells the piano to start its own metronome (MIDI Start), and pausing stops it. The tempo and sound are the piano's own metronome settings. Not every piano reacts to this: use the two buttons to test yours.

Some instruments follow the tempo of incoming MIDI clock when set to external sync. Harmless if yours ignores it.

How long before its time the next key (or chord) lights up on the keyboard in Learn mode. It also shows over a key that is still sounding. Only the next note is ever shown, never the one after.

Left / right hand

The hands follow the split slider in the top bar (and its new splits). This works for any file, also when it has two channels: they are then treated as one.

Display

Stops the tablet from locking while you play, which can cut the USB MIDI connection.

Export / import (beta)

The MIDI export has two tracks: left hand on channel 1, right hand on channel 2, following the splits in force. Parts you left out are not exported. The splits file remembers which MIDI file it belongs to; loading it into another file asks first.

Advanced training

Adds a bar under the top bar: a loop counter (stops after the number of loops you choose) and your accuracy in Learn mode: the last notes, and the total.

Each note or chord scores 100% when you play it within the first value of the music, then falls in a straight line to 0% at the second value. A note you miss scores 0%. Pressing "Wait for me" keys late also counts as late.
